# нАмерок — Telegram Mini App (GitHub + Vercel + Neon)

Структура:
- `index.html` — игра (статика)
- `api/sync.js` — сервер на Vercel; `lib/engine.js` — игровая логика на сервере (баланс, крутки, инвентарь, машины, бонусы, рынок, админка)
- `schema.sql` — таблицы для Neon

## Запуск
1. **Neon.** Создай проект на neon.tech. Скопируй Connection string (формат `postgresql://...`). Открой SQL Editor и выполни содержимое `schema.sql`.
2. **Бот.** В Telegram: @BotFather → `/newbot`. Сохрани токен.
3. **GitHub.** Создай репозиторий и загрузи все файлы из этой папки (кроме `.env`).
4. **Vercel.** Add New → Project → выбери репозиторий. В Environment Variables добавь:
   - `DATABASE_URL` — строка из Neon
   - `BOT_TOKEN` — токен бота
   Нажми Deploy. Получишь адрес вида `https://namerok.vercel.app`.
5. **Mini App.** В BotFather: `/newapp` → выбери бота → вставь адрес Vercel. Для кнопки в чате: `/mybots` → бот → Bot Settings → Menu Button → тот же адрес.

## Как это работает
- Сервер проверяет подпись Telegram (`initData`) токеном бота. Без Telegram облако отключено, игра работает локально в браузере.
- В Neon хранятся: полное сохранение игрока, общий рынок (таблица `market`), рейтинг (капитал, номера, лега+, доход/ч, кланы), владельцы секретного и абсолютного номера, последнее объявление о выпадении.

## Ограничения
- Баланс и инвентарь считаются на стороне клиента, поэтому ловкий игрок может подделать данные. Для честного рейтинга нужно переносить крутки на сервер.
- Админка с PIN удалена из меню.

## Рынок
Лоты хранятся в Neon. Покупка атомарная (один лот купит только один игрок). Продавец забирает деньги кнопкой в Рынке, комиссия 5%. Если схема уже была создана ранее, выполни в Neon только блок `market` из `schema.sql`.

## Сохранение
Прогресс (баланс, номера, машины, клан) сохраняется в Neon автоматически: через 2,5 секунды после изменения и при сворачивании игры. Версия сохранения хранится на сервере, поэтому старое устройство не затирает новый прогресс. «Сбросить прогресс» в настройках удаляет и данные на сервере. Менять базу не нужно.

## Сервер считает всё
Клиент присылает только действия (крутка, продажа, покупка). Баланс, инвентарь, редкости и тираж номеров считает сервер, подделать их в браузере нельзя.

## Тираж секретных и абсолютных
На каждый регион выпускается 15–20 секретных (число случайное при первом выпадении) и 5 абсолютных номеров. Выпущенные номера не возвращаются в тираж. Когда тираж региона исчерпан, вместо номера выпадает мифик. Тираж меняется в админке.

## Админка
Добавь в Vercel переменную `ADMIN_IDS` со своим Telegram ID (узнать: @userinfobot; несколько ID через запятую). После Redeploy в меню появится «Админ-панель». У остальных пункта нет, а сервер отклоняет админские команды от любых других ID.

## Обновление базы
Если таблицы уже созданы по прошлой версии, выполни в Neon:
```sql
drop table if exists uniques;
create table if not exists supply (kind text not null, region text not null, cap int not null, taken int not null default 0, primary key (kind, region));
create table if not exists cfg (key text primary key, val jsonb);
```

## Сезон и обнуление
Сезон BETA-1 стартует при первом запросе к серверу и длится 2 дня 9 часов. В админке можно запустить новый сезон (название в поле текста, часы в поле числа), обнулить одного игрока по его Telegram ID или всех сразу (с подтверждением). При обнулении всех тираж секреток и абсолютов тоже сбрасывается.

## Дуэли, апгрейд, очки клана
- Дуэли идут только между настоящими игроками (ставка замораживается, победитель получает ×1,9). Нужна таблица `duels`: выполни в Neon последний блок `create table ... duels` из `schema.sql`.
- Апгрейд: множитель x2, x5 или x10, шанс успеха 95%/множитель, при неудаче номер сгорает.
- Задания ДПС дают очки клана; рейтинг кланов считается по ним.

## Что добавлено в этой версии
- **Клановая война.** Очки за каждый выбитый номер (1/4/15/40/100/175/300/500 по редкости), итоги каждый понедельник (UTC). Победившему клану (тем, кто принёс очки) выдаётся удача ×2 на 24 часа и значок в профиль, у клана значок победителя. Нужна таблица `cw`.
- **Президентские номера.** 3 штуки на регион, стоимость 5–10 млрд ₽.
- **Цены меняются** каждый час (курс по редкостям виден в инвентаре).
- **Профиль:** меню → Профиль.
- **Страна дня и множитель мифика** меняются в админке.
- **Реферальная ссылка.** Добавь в Vercel переменную `BOT_LINK`: `username_бота/короткое_имя_приложения` (например `namerok_bot/play`) для ссылки на приложение, созданное через `/newapp`. Нужна таблица `refs`.
- Звук прокрутки включается и выключается в настройках.

### SQL для обновления базы
```sql
create table if not exists cw (week text not null, clan text not null, pts int not null default 0, primary key (week, clan));
create table if not exists refs (invitee bigint primary key, inviter bigint not null, paid boolean not null default false, created_at bigint not null);
create index if not exists refs_inviter_idx on refs (inviter);
```

## Обновление: престижи, цель недели, казна клана, переводы
Выполни в Neon блок из конца `schema.sql` (alter players + таблицы `clans` и `goal`). Подробности про BOT_LINK и таблицы `cw`, `refs` выше.
Новое: престиж (10 ступеней), общая цель недели (100 000 круток), полировка (300 нажатий по 3 000 ₽), круглая рулетка, батл пасс на 30 уровней, рамки для номеров, переводы по @username, казна клана, медали за топ-3 сезона, онлайн в настройках, ещё 6 стран, 34 региона без наценки, премиум-крутка с 5 уровня, элитная с 10, кланы с 10 уровня, комиссия при продаже 15%.

## Обновление: сброс сезона, аукцион, клановая война
В Neon выполни последние строки `schema.sql`: таблицы `auction` и `bids`. Аукцион идёт в субботу и воскресенье (по Москве), лот создаётся автоматически. Война недели считается по Москве, турнир каждую субботу 19:00–21:00 даёт очки ×3. «Сброс после сезона» находится в админке.
